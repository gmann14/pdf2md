## Why this exists

pdf2md is a browser-first PDF to Markdown converter, but the product is only half of the job. Good PDF conversion needs clear explanations of what works, what fails, and how to use the output in real workflows.

This blog is the on-site home for those notes. The converter remains the first screen, while longer guides live here so they can be indexed, linked, and updated without crowding the tool.

## What will go here

- Practical conversion guides for reports, articles, tables, and technical documents
- Notes on AI and RAG workflows that need clean Markdown instead of raw PDF text
- Technical explainers on PDF.js extraction, heading detection, links, tables, and code blocks
- Honest limitations for scanned PDFs, complex tables, formulas, and ambiguous reading order

## The privacy model stays the same

The blog does not change the converter's privacy model. PDF files are processed in the browser, and file bytes, filenames, extracted text, generated Markdown, and PDF metadata are not uploaded by the app.
